# 🕹️ AnberJS

> A lightweight, browser-based handheld console shell and mini-OS inspired by retro hardware. Built strictly with vanilla HTML, CSS, and JavaScript.

### 🚀 Features
* **Physical Shell Replica:** Functional D-Pad, ABXY, Start, Select, and Menu controls mapped to mouse clicks and keyboard inputs.
* **Mini OS Launcher:** A 3x3 grid interface with active state handling for browsing and launching games.
* **Pure Web Tech:** Zero dependencies, lightweight, and fully responsive.
